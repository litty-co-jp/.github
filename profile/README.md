# LiTTY

## About LiTTY

We plan, build, and operate web services and applications.

Our name comes from “Live true to yourself”—a simple message at the heart of LiTTY.

## EMIANO

**Every Moment Is A New Opportunity.**

EMIANO is our WordPress plugin brand, bringing the spirit of LiTTY into everyday tools.

We create plugins that are enjoyable to use and bring small surprises, discoveries, and new possibilities to everyday moments.
