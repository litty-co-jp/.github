# LiTTY｜株式会社リティ

## About LiTTY

ウェブサイト・ウェブコンテンツ・インターネットサービス、および各種アプリケーションソフトの企画・開発・制作から、提供・販売・運営・保守管理までを行っています。

LiTTYは、「Live true to yourself（自分らしく生きる）」というメッセージから生まれた社名です。

## EMIANO｜エミアノ

EMIANOは、株式会社リティが展開するWordPressプラグインのブランドです。

LiTTYの「自分らしく生きる」という理念を受け継ぎ、日々の中に新しい可能性を届けたいという考えから生まれました。

「Every Moment Is A New Opportunity」
——すべての瞬間が、新しい可能性。

使うこと自体が楽しく、ワクワクする。日常の何気ない瞬間に、新しい可能性・発見・喜びを届ける製品づくりを目指しています。
